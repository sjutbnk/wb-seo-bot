# WB SEO Bot

Telegram-бот для генерации SEO-оптимизированных карточек товаров Wildberries.

## Как работает

1. **Ключевые слова** — получает автоподсказки из реального поиска WB
2. **Анализ конкурентов** — парсит топ-10 товаров в выдаче WB, извлекает их названия и описания
3. **Генерация SEO** — Gemini 2.5 Flash создаёт структурированную карточку

## Быстрый старт

### 1. Настройка переменных окружения

```bash
cp .env.example .env
# Заполни BOT_TOKEN и GEMINI_API_KEY в файле .env
```

Где получить ключи:
- `BOT_TOKEN` → [@BotFather](https://t.me/BotFather) в Telegram
- `GEMINI_API_KEY` → [Google AI Studio](https://aistudio.google.com/apikey) (бесплатно)

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Запуск

```bash
python main.py
```

## Структура проекта

```
├── main.py              # Точка входа
├── config.py            # Настройки (pydantic-settings)
├── handlers/
│   ├── start.py         # /start команда
│   └── seo.py           # Основной хэндлер генерации SEO
└── services/
    ├── wb_api.py        # WB API: ключевые слова + конкуренты
    └── gemini_seo.py    # Генерация SEO через Gemini 2.5 Flash
```

## Настройки (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен Telegram-бота |
| `GEMINI_API_KEY` | — | Ключ Gemini API |
| `COMPETITORS_COUNT` | `10` | Количество конкурентов для анализа |
| `SUGGESTIONS_COUNT` | `20` | Количество ключевых слов из WB |
